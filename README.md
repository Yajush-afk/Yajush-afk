## About

I am a Computer Science Engineering student at MAIT ('28) building reliable, local-first AI systems across LLM agents, machine learning, computer vision, and backend engineering. As the founder and builder of [BrandNewDevs](https://github.com/BrandNewDevs), I care about turning ambitious AI ideas into systems with clear boundaries, thoughtful design, and practical value.

I am open to AI/ML engineering internships, technical collaboration, and impactful open-source work.

## Selected Work

### [WorkBench](https://github.com/BrandNewDevs/WorkBench)

A local-first AI workbench for confidential industrial documents, built so sensitive workflows can remain on-device. It combines an Electron and React desktop client with Python services built on FastAPI and Ollama.

`Electron` · `React` · `FastAPI` · `Ollama`

### [SAGE](https://github.com/Yajush-afk/SAGE)

A local-first voice and text command layer for developer laptops that treats model output as an untrusted proposal. Typed plans, safety policies, registered tools, and SQLite audit records keep execution deliberate and inspectable.

`FastAPI` · `Ollama` · `SQLite` · `Electron`

### [RouteMinds](https://github.com/Yajush-afk/RouteMinds)

A Delhi transit intelligence project for route rationalisation, delay prediction, and route selection. It combines GTFS data, XGBoost travel-time prediction, FastAPI services, and reliability-aware route optimisation.

`Python` · `XGBoost` · `FastAPI` · `GTFS`

### [Jutsu Battle](https://github.com/Yajush-afk/jutsu-battle)

An offline webcam-controlled battle game where hand-seal sequences become in-game actions. The system separates real-time gesture recognition from the combat engine, using local computer vision and a PyTorch classifier.

`PyTorch` · `OpenCV` · `Pygame` · `Computer Vision`
